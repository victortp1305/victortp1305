## 🚀 Projetos

### 🏥 Automação de Atendimento para Farmácia (WhatsApp + IA)

Sistema de automação de atendimento para farmácia de manipulação com alto volume de clientes, utilizando chatbot, agentes de IA e integrações.

**Contexto:**
- ~100 atendimentos por dia via WhatsApp  
- Necessidade de escalar atendimento e reduzir operação manual  

**Solução:**
- Chatbot para triagem inicial  
- Orçamentista humano para validação  
- Automação completa após aprovação  

**Fluxo:**
1. Cliente entra via WhatsApp  
2. Chatbot faz triagem  
3. Orçamentista envia orçamento  
4. Após aprovação:
   - Agente negocia entrega e pagamento  
   - Agente gera link de pagamento  
   - Agente valida pagamento  
   - Agente realiza cadastro  
5. Atendimento finalizado automaticamente  

**Tecnologias:**
- Node.js  
- APIs REST  
- Webhooks  
- n8n  
- Integração com CRM de WhatsApp  
- Engenharia de prompts para IA  

**Diferenciais:**
- Arquitetura híbrida (humano + IA)  
- Automação de ponta a ponta  
- Separação de responsabilidades entre agentes  
- Escalabilidade do atendimento

### 💍 Plataforma de Site de Casamento

Aplicação fullstack para criação de sites personalizados de casamento com painel administrativo e integração com produtos.

**Problema:**
Centralizar informações do evento e lista de presentes de forma organizada

**Solução:**
Sistema com:
- Site público personalizado  
- Painel admin  
- Cadastro de produtos  
- Integração com marketplace  

**Fluxo:**
1. Usuário cadastra produto  
2. Backend processa requisição  
3. Webhook gera link de produto  
4. Dados salvos no banco  
5. Frontend atualiza automaticamente  

**Tecnologias:**
- React  
- TypeScript  
- Node.js  
- Supabase  
- Webhooks
